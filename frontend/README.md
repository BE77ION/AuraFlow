# AuraFlow — Frontend

React 19 + Vite frontend for the AuraFlow Team Task Manager.

See the [root README](../README.md) for full setup instructions, API reference, and project overview.

## Development

```bash
npm install
npm run dev        # Start dev server at http://localhost:5173
npm run build      # Production build
npm run preview    # Preview production build
```

## Key Dependencies

- **React 19** + **React Router 7** — UI & routing
- **Axios** — API requests with JWT interceptor
- **date-fns** — Date formatting and overdue detection
- **lucide-react** — Icons
- **react-hot-toast** — Notifications
